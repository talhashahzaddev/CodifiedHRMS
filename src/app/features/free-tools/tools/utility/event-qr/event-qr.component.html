How Does an Event QR Code Work?

In iCal Event mode, the QR code encodes a standard BEGIN:VCALENDAR vEvent string. When scanned on iOS, the phone immediately offers to add the event to Apple Calendar. On Android, apps like Google Calendar or any QR scanning app with calendar integration will pick it up.

In URL mode, the QR simply encodes a web address — useful when you want to link attendees to an Eventbrite page, a Zoom join link, a Google Meet room, or any registration form.
