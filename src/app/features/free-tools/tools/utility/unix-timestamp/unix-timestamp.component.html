What is a Unix Epoch Timestamp?

A Unix Timestamp (or Epoch time) is a system for describing a point in time. It is defined as the number of seconds that have elapsed since the Unix Epoch—midnight Coordinated Universal Time (UTC) on January 1, 1970—minus leap seconds.

Why Do Computers Use Epoch Time?

Storing dates as a single integer (the number of seconds) is incredibly efficient for computer systems and databases. It completely bypasses the complexities of time zones, daylight saving time, and varying month lengths. Developers use Epoch time to ensure reliable cross-platform time sorting and arithmetic.

How to Convert Timestamps

To decode a timestamp, enter the integer (in seconds or milliseconds) into the top box to instantly see the human-readable UTC and local time. To encode a date, select a local date and time in the bottom section, and the tool will generate the corresponding Unix timestamp.
