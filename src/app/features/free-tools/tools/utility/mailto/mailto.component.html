What is a Mailto Link?

A mailto: link is a standard HTML hyperlink that instructs the browser to open the user's default email client (Gmail, Outlook, Apple Mail, Thunderbird, etc.) and pre-populate a new compose window with your specified fields. It's the simplest way to add a "Contact Us" or "Email Us" button to any website without a backend form or server.

The basic syntax is: mailto:recipient@example.com?subject=Hello&body=Hi%20there. Every parameter must be URL-encoded — which is exactly what this generator handles automatically.

Why URL Encoding Matters

Without proper encoding, special characters like spaces, line breaks, ampersands, and question marks will break the mailto link. For example, a space must become %20, a newline becomes %0A, and an ampersand becomes %26. Our generator applies encodeURIComponent() to the Subject and Body fields, and uses the correct & delimiter between parameters so the link works across all browsers and email clients.
