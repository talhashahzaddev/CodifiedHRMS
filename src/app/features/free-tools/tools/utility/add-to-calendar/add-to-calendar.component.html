What is an "Add to Calendar" Link?

An "Add to Calendar" link is a specially crafted URL that, when clicked, opens the user's preferred calendar application with the event details pre-filled. Instead of manually typing event information, your attendees can add your event to their calendar in a single click — reducing friction and improving event attendance.

There are three main formats: a direct Google Calendar URL, an Outlook Web compose link, a Yahoo Calendar URL, and a downloadable .ics file (iCalendar format, RFC 5545) for all other calendar apps.

How the Date Format Works

Google Calendar and Yahoo Calendar require dates in the UTC-based format YYYYMMDDTHHmmssZ. The "Z" suffix indicates the time is expressed in Coordinated Universal Time (UTC). Our generator automatically converts your local date and time input to UTC, so attendees in any timezone see the correct local time.

Outlook Web accepts ISO 8601 format (YYYY-MM-DDTHH:mm:ss), while the .ics file uses the same UTC format with CRLF line endings as required by RFC 5545.

How to Use These Links

  • Enter your event title, start/end date and time, and optional location and description.
  • Click "Generate Links" to instantly create all four calendar link formats.
  • Copy the Google, Outlook, or Yahoo link and paste it into your email, website, or newsletter.
  • Download the .ics file to send as an email attachment — recipients can open it with any calendar app.
  • For all-day events, toggle "All-Day Event" before generating — time fields will be hidden automatically.
